# 브랜드 필름 리뉴얼 시안 (22초 샘플 2종)

목표: 지금 본편의 "AI 티"(모든 요소가 빛남, 그라데이션 과다, 평평한 벡터, 똑같은 글자 등장)를 덜고 더 세련되게.
두 시안은 **같은 이야기, 같은 타이밍, 같은 소리**라 나란히 비교할 수 있다. 인트로·아웃트로 로고 부분은 손대지 않는다.

| 구간 | 내용 |
| --- | --- |
| 0.0–4.2 | 목소리에서 시작 |
| 4.2–12.3 | AI 콜봇 4단계: 음성 인식 → 의도 파악 → 목소리 인증 → 업무 처리 |
| 12.3–17.0 | 대화 아래의 인프라(데이터센터) |
| 17.0–22.0 | AI + 인프라, 한 팀(클라이맥스) |

## A안: 에디토리얼 (`out/rapeech_sample_A_editorial.mp4`)
- 빛나는 것은 목소리 점 하나뿐. 선은 2px 흰 선, 노드는 가는 고리(16 라인 애니메이션)
- 선은 점이 지나간 자리까지만 그려짐(점과 선이 같은 트윈)
- 배경: 아주 느리게 흐르는 그라데이션 + 고운 필름 질감(19 그레이니 그라디언트)
- 글자: 줄 단위 마스크로 올라오는 키네틱 타이포(06), 그라데이션은 한 단어만, 동사는 단계마다 하나씩 켜짐
- 단계 값은 텍스트 스크램블(11)로 맞춰짐
- 데이터센터: 가는 선으로 그린 등각 층(05), 여섯 층이 두 층(AI·인프라)으로 모이는 클라이맥스

## B안: 3D 재질 (`out/rapeech_sample_B_3d.mp4`)
- 목소리 = 액체 금속 구(01 리퀴드 + 14 셰이프 모프). 단계마다 표면이 바뀜: 물결(인식) → 숨(이해) → 지문 고리(인증)
- 구가 관문 4개를 통과, 지나온 길만 빛남
- 바닥이 사라지며 아래의 실제 3D 서버 랙(무광 재질, LED만 발광)이 드러남
- 클라이맥스: 구가 떠올라 납작한 AI 판으로 바뀌고, 빛기둥이 인프라에 닿으며 LED가 가운데서 물결처럼 켜짐
- three.js(시간만으로 그리는 결정적 렌더)

## 다시 만들기
```bash
python3 video/samples/build_samples.py
cd video/samples/a && npx hyperframes render --fps 60 --quality delivery --output out/raw.mp4
cd video/samples/b && npx hyperframes render --fps 60 --quality delivery --output out/raw.mp4
```
B안의 three.js(r128)는 `fx/vendor/three.min.js`에서 복사한다(모션 라이브러리 작업 폴더).
소리는 임시(합성 배경음악 + 띠링), 본편 적용 시 내레이션 타이밍에 맞춘다.
